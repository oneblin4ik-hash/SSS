# Страница оффера трипваера

Продающая страница курса «Первые шаги к форме» — единственный кусок
воронки, которого раньше не было ни в одном виде.

```bash
python3 build_offer.py
```

На выходе три файла в `out/`:

| Файл | Зачем |
|---|---|
| `offer.html` | полноценная страница, открывается двойным кликом |
| `offer-artifact.html` | то же со снятой обёрткой документа — для публикации артефактом |
| `offer-template.html` | с неподставленными `{{name}}` и `{{level}}` — этот отдаём разработчику бота |

Шрифты вшиты в base64, аватар тоже: в артефактах на claude.ai строгий CSP,
внешние хосты режутся. Сборка проверяет и печатает «Внешних ресурсов нет».

## Чего в макете брать было нельзя

Хендофф сам помечает контент этой секции как черновой: «цифры отзывов, тексты
FAQ — заменяются реальными материалами клиента». В макете стоят:

* отзыв «Артём, 34»;
* «1 240 прошли разбор»;
* оценка «4,9»;
* зачёркнутая старая цена 4 900 ₽ и чип «−80%»;
* возврат денег в первые три дня.

Ничего этого в спеке нет, и ничего из этого не придумано. Это не оформление, а
фактические утверждения и финансовые обязательства: выдуманный отзыв и
несуществующий возврат — прямой обман покупателя. Вместо них в правой колонке
стоит явная заглушка. Подставь реальные цифры или удали блок `.ph` целиком —
вёрстка не поедет.

## Таймера нет сознательно

Crimson запрещает таймеры и «осталось 3 места». Ни отсчёта, ни счётчика мест,
ни дедлайна на странице нет.

Зачёркнутой цены тоже нет. Раньше рядом с 690 ₽ стояли перечёркнутые 1 990 ₽
как обещание, что цена поднимется. Цена стала 1 890 ₽ — при такой разнице
«старая» цифра превратилась бы в украшение, а цена, по которой не продавали,
в роли старой это недостоверная реклама, ст. 10 ЗоЗПП. Поэтому её убрали
совсем.

## Персонализация

Те же плейсхолдеры, что у лид-магнита, чтобы бот подставлял значения из одного
и того же JSON квиза:

* `{{name}}` — имя (ключ `n`);
* `{{level}}` — уровень по типу срыва, например «🛡 Закрепление» (ключ `t`).

Плашка с уровнем — единственное персональное место на странице. Если бот
отдаёт страницу неперсонализированной, её можно просто убрать.
