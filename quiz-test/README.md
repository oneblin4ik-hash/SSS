# Кликабельная демка квиза

Автономная сборка `app/kviz-serbolin.html` — чтобы прокликать все 14 экранов в
обычном браузере, без Telegram, и увидеть payload, который ушёл бы боту.

```bash
python3 build_quiz_demo.py     # → out/kviz-demo.html и out/kviz-artifact.html
python3 test_quiz_demo.py      # прогон 14 экранов в Chromium
```

`out/kviz-demo.html` открывается двойным кликом. `out/kviz-artifact.html` —
то же самое, но со снятой обёрткой документа, для публикации артефактом на
claude.ai (публикатор оборачивает файл в свои `<!doctype>/<head>/<body>`).

## Что меняется относительно оригинала

Логика квиза не трогается вообще — тестировать нужно то, что поедет в прод.
Трогать её и не пришлось: автор везде проверяет `tg` на null, а `submit()` без
Telegram и без `CFG.API` сам сваливается в `console.log`. Мы цепляемся к этой
ветке.

1. Выкидывается `<script>` Telegram SDK и `<link>` на Google Fonts.
2. Вместо них — `@font-face` с woff2 в base64 (кириллица и латиница).
3. К `console.log('QUIZ RESULT', data)` дописывается вызов оверлея.
4. Перед `</body>` добавляется тест-оверлей с payload.

Всё внешнее убирается не для красоты: в артефактах на claude.ai работает
строгий CSP, любой внешний хост режется. Страница молча уехала бы на системный
шрифт. Сборка проверяет это сама и печатает «Внешних ресурсов нет».

## Тест-оверлей

Появляется на последнем экране, когда квиз вызывает `sendData`. Показывает:

* расшифровку всех 20 полей payload, ключевые (`bp`, `t`, `bmi`) подсвечены;
* название типа срыва по номеру — чтобы проверить `typeOf()` не сверяясь с кодом;
* предупреждение, если в `hl` пришло `heart` или `diab` (тогда в «День 0» и в
  первый урок обязателен абзац про врача);
* сырой JSON и его размер против лимита `sendData` в 4096 байт.

Оформлен токенами самого квиза (`--ink`, `--gold`, `--plat`, Playfair,
JetBrains Mono). Своей палитры не заводили: оверлей живёт в том же документе,
и вторая визуальная система смотрелась бы там чужой вставкой.

## Автотест

`test_quiz_demo.py` прокликивает 14 экранов за Галину из спеки (165 см,
78 → 66 кг, срыв на 2–3 неделе, 4–6 заходов) и проверяет, что payload сошёлся:
ожидается тип 4 и ИМТ 28,7. Заодно ловит ошибки JS и любой сетевой запрос
наружу.

Смысл не в проверке логики квиза — она уже гонялась через jsdom на пяти
персонажах. Смысл в том, чтобы ловить поломки сборки: не подхватился шрифт,
не сработал хук, ошибка в JS оверлея. Такое по скриншоту видно не всегда, а
кликать 14 экранов руками на каждой правке долго.

Скриншоты ключевых экранов складываются в `shots/`.

## Если квиз поменяли

Положить новый `kviz-serbolin.html` в эту папку и пересобрать. Сборка падает с
понятной ошибкой, если не нашла что-то из того, что собиралась заменить, —
молча выдать сломанную демку она не может.
