# Дизайн-система Mr. Serbolin

Источник: `brandbook_mr_serbolin.pdf` (официальный брендбук) + фактическая реализация
в `app/kviz-serbolin.html` (переменные `:root`, строки 17–29). Если брендбук и код
разойдутся — код в квизе главнее, потому что это уже проверенная в проде версия.

## Цвета

| Токен | Hex | Роль |
|---|---|---|
| `--ink` | `#222222` | Основной фон (Eerie Black из брендбука) |
| `--ink-2` | `#2A2A2A` | Карточки, приподнятые поверхности |
| `--ink-3` | `#343434` | Полосы прогресса, разделители |
| `--line` | `#3D3D3D` | Рамки, обводки |
| `--gold` | `#D4A843` | Акцент. Кнопки, иконки, ключевые цифры. **Не больше 15–20% площади экрана** — так в брендбуке, и это подтверждено практикой: золото держит фокус только пока его мало |
| `--gold-deep` | `#8C6F2C` | Тени/градиенты на золоте, неактивные состояния |
| `--plat` | `#E6E6E6` | Platinum. Основной текст |
| `--muted` | `#8F8F8F` | Второстепенный текст, подписи |
| `--risk` | `#D9584C` | Только зона риска / предупреждения. Не декоративный цвет |
| `--white` | `#FFFFFF` | Чистые светлые поверхности, если понадобится светлая версия |

## Типографика

- **Заголовки** — Playfair Display (900), в брендбуке указан DejaVu Serif — Playfair
  ближайший веб-аналог по характеру: контрастный, премиальный, с засечками.
- **Основной текст** — Inter, аналог DejaVu Sans из брендбука.
- **Числа/данные** — JetBrains Mono, только для цифр (недели, кг, %) — это не в
  брендбуке, добавлено в квизе для читаемости цифр в узкой колонке.
- Правила из брендбука, которые обязательны везде: текст не мельче 10pt в печати
  (соответствует ~15px в PDF), заголовки с воздухом вокруг, короткие абзацы без
  «простыней», выравнивание текста по левому краю, заголовков на обложке — по центру.

## Форма и отступы

- Радиус скругления: `14px` (переменная `--r`) — единый на кнопках, карточках, полях.
- Контентная колонка: max-width 520px, дальше — воздух, не растягивать текст на всю ширину.
- Один смысловой блок = одна карточка с отступом, не сливать в простыню.

## Голос (из брендбука, раздел «Голос бренда»)

- На «ты», всегда.
- По-дружески, с экспертизой, юмор уместен.
- Без канцелярита: не «данный продукт», не «осуществить», не «в рамках».
- Без снисходительности: не «это все знают».
- Без наукообразия без объяснений.
- Без нытья — говорим про решения.
- Без агрессивных продаж — убеждаем ценностью.
- Фирменные фразы, которые можно использовать как акценты (не в каждом документе,
  дозированно): «Терпение + Дисциплина = Результат», «Будь в форме не к лету, а
  всегда», «Не жди результат — научись получать удовольствие от процесса».

## Референс-актив

`avatar.png` в этой папке — аватар Эдуарда (жёлтый круг, персонаж), используется
в Telegram/Instagram и уже вшит в квиз (`app/kviz-serbolin.html`, константа
`AVATAR_B64`). Использовать как единственный «портрет» бренда — фото самого
Эдуарда в документах не использовать, чтобы не плодить два визуальных языка.

## Применение к PDF (лид-магнит, трипваер)

Тёмный фон `--ink` в печатном PDF утяжеляет документ и плохо ведёт себя при
печати на обычном принтере — для лид-магнита и уроков трипваера рекомендую
**светлую бумажную версию**: белый фон (`--white`), текст `--ink` вместо
`--plat`, золото остаётся акцентом (заголовки, буллеты, разделители, номера
уроков), платина уходит в подписи/сноски. Тёмная версия — только для превью-
обложки первой страницы каждого PDF (как обложка брендбука), чтобы сохранить
премиальность с первого взгляда, а дальше — читаемая светлая вёрстка.
